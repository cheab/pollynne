# Pollynne Leite Beauty

Website moderno e responsivo para Pollynne Leite Beauty, especialista em serviços de beleza natural.

## 🚀 Características

- ✨ Design moderno e minimalista
- 📱 Totalmente responsivo (mobile-first)
- ⚡ Performance otimizada com Next.js 14
- 🎨 Cores e tipografia elegantes
- 📱 Otimizado para dispositivos móveis
- 🔧 Fácil de manter e customizar

## 🛠️ Tecnologias

- **Next.js 14** - Framework React moderno
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS
- **Vercel** - Hospedagem e deployment

## 📦 Instalação

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/pollynne.git
cd pollynne
```

2. Instale as dependências:
```bash
npm install
```

3. Execute o servidor de desenvolvimento:
```bash
npm run dev
```

4. Abra [http://localhost:3000](http://localhost:3000) no seu navegador.

## 🚀 Deploy na Vercel

1. Push seu código para GitHub
2. Acesse [vercel.com](https://vercel.com)
3. Conecte seu repositório
4. Configurar domínio customizado: `pollynne.com.br`
5. Deploy automático em cada push para main
