## 💡 Dicas Importantes

1. **Mobile First**: O site foi pensado para celular primeiro. Teste sempre em celular!
2. **WhatsApp**: Atualize o número em TODOS os 4 componentes (Header, Hero, Gallery, Footer)
3. **Imagens**: Adicione fotos reais para impacto máximo
4. **SEO**: Personalize título e descrição em `app/layout.tsx`
5. **Domínio**: Configure `pollynne.com.br` durante o deployment na Vercel

## 🆘 Precisa de Ajuda?

1. **Erro na inicialização**: Verifique `npm install`
2. **Domínio não funciona**: Aguarde 48h para DNS propagar
3. **Dúvida sobre código**: Veja os comentários no código
4. **Quer adicionar feature**: Consulte docs do Next.js e Tailwind
